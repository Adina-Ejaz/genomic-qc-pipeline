# Automated Genomic Sequencing Quality-Control and Reporting Pipeline

## Project Overview

This project aims to develop an automated quality-control pipeline for genomic sequencing data.

The pipeline will take sequencing data in FASTQ format, analyse selected quality metrics, identify potential quality issues, and generate an interpretable quality-control report.

## Planned Workflow

FASTQ data
↓
Quality Control
↓
Quality Metric Extraction
↓
QC Analysis
↓
PASS / WARNING / FAIL
↓
Visualisation
↓
QC Report

## Current Stage

**Day 1 — Initial setup and FastQC analysis**

The initial stage of the project focuses on understanding FASTQ data and using FastQC to perform an initial quality-control assessment.

## Technologies

* Python
* FastQC
* Bash / command line
* Git and GitHub

Additional tools may be introduced as the project develops.

## Dataset

The project uses publicly available sequencing data for development and testing.

No patient-identifiable data is used.
